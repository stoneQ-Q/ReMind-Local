# ReMind 云端架构 V1

> 状态：方案基线  
> 日期：2026-07-29  
> 目标：在不破坏当前 1.0.2 本地版本的前提下，为私密测试版建立可控成本、可迁移的云端能力。

## 1. 已确定的产品模式

ReMind 保留两种彼此独立的使用方式。

### 1.1 自助部署版

- 沿用当前已经可用的方案。
- 用户自行准备 Mac、安装服务并配置自己的 API Key。
- 手机与 Mac 必须处于同一网络。
- 不承诺 Windows、Linux、异地访问或零配置安装。
- ReMind 不承担用户的服务器费和 AI 调用费。

这一模式用于验证真实需求，也服务于愿意自己折腾、希望完全掌控数据和成本的用户。

### 1.2 云端托管版

- 用户安装 App 后即可使用，不依赖家中电脑。
- 微信消息接收、链接解析、图片和视频处理、语音识别、异步任务都在云端完成。
- 用户数据、凭据、余额和任务必须按账号隔离。
- 私密测试阶段使用香港节点；具备备案和上架条件后，再评估迁移到中国大陆节点。

## 2. 云端版的 AI 使用方式

每个用户可以独立选择：

1. **关闭 AI**：仅使用不依赖模型的记录、同步和基础整理能力。
2. **使用自己的 API Key**：用户承担模型费用，ReMind 只收取明确展示的云端处理费用。
3. **使用 ReMind 托管额度**：ReMind 代付模型费用，用户预充值后按实际消耗扣费。

用户自己的 API Key 不写入 App 数据库、不进入日志，也不以明文保存在业务数据库中。App 只负责通过加密连接提交；服务端使用独立的密钥托管层加密保存，并只在发起对应模型请求时解密。

## 3. 最小云端架构

```text
手机 App
   │ HTTPS
   ▼
API 服务 ─────── PostgreSQL
   │                  │
   ├── 账号与设备      ├── 用户与权限
   ├── 笔记同步        ├── 任务状态
   ├── API Key 管理    └── 余额与账本
   │
   ├──────── 对象存储（图片、音视频、临时文件）
   │
   └──────── 任务队列 ── Worker
                         ├── 微信轮询
                         ├── 网页/小红书解析
                         ├── 图片与视频分析
                         └── ASR/AI 模型调用
```

私密测试初期可将 API、Worker 和 PostgreSQL 放在同一台腾讯云香港主机上，以降低固定成本；代码和数据边界仍按独立组件设计，用户增长后可以逐项拆分。

## 4. 第一阶段技术约束

- 应用服务使用 Docker 运行，不依赖腾讯云专有运行时。
- 数据库使用标准 PostgreSQL，不在业务代码中绑定厂商专有语法。
- 对象存储通过统一接口访问，首期接腾讯云 COS，未来可替换阿里云 OSS 或其他 S3 兼容服务。
- 密钥托管通过统一接口访问，首期可以使用主机密钥加密；正式收费前升级为云 KMS。
- 所有外部服务地址通过配置注入，不硬编码在 App 或服务代码中。
- 用户、设备、微信连接、笔记、任务、文件、API Key 和账本都必须带有明确的 `user_id` 所属关系。
- 日志默认脱敏，不记录微信令牌、API Key、完整消息正文和下载链接中的敏感参数。

## 5. 计费与成本熔断

云端版采用预付费余额，禁止产生负余额。

每个收费任务按以下顺序执行：

1. 在 App 中展示预计费用或费用范围。
2. 服务端预占本次任务额度。
3. Worker 执行任务并记录可核验的实际消耗。
4. 成功后按实际消耗结算，多余预占额度退回。
5. 失败或取消时释放预占额度；已经产生且不可退回的第三方费用按规则结算。

必须同时设置：

- 单任务最高费用；
- 单用户每日和每月上限；
- 全平台每日和每月预算上限；
- 视频时长、文件大小和模型调用次数上限；
- 高费用视频任务的二次确认；
- 第三方接口异常时的自动暂停和告警。

第一批私密测试用户不直接开放无限量托管 AI。默认给少量体验额度，超出后必须充值或切换为自己的 API Key。

## 6. 部署与迁移路线

### 阶段 A：本地云端化

- 不购买服务器。
- 在开发机上用容器运行 PostgreSQL、API、队列和 Worker。
- 用测试账号验证多用户隔离、任务重试、API Key 加密和计费账本。
- App 可在“本地模式”和“云端测试模式”之间切换。

### 阶段 B：腾讯云香港私密测试

- 单台轻量应用服务器起步，配对象存储和异地备份。
- 先做 7 至 14 天中国移动、联通、电信网络实测。
- 重点观察 App API、微信连接、链接抓取、视频下载和模型供应商出口的成功率与延迟。
- 达到稳定性门槛后才邀请首批用户。

### 阶段 C：付费小规模运行

- API 与 Worker 至少拆分为两个运行实例。
- PostgreSQL 迁移到独立实例或托管数据库。
- 启用 KMS、集中日志、自动备份、监控和告警。
- 根据真实使用量修正积分价格和免费额度。

### 阶段 D：中国大陆节点

- 完成 ICP 备案、App 备案及所需合规工作后再迁移。
- 通过标准 PostgreSQL 备份恢复、对象存储同步和 DNS 切换完成迁移。
- 香港节点可保留为回退环境或海外服务节点。

## 7. 当前不做的事项

- 不为自助部署版开发 Windows/Linux 完整安装器。
- 不实现手机从外网连接家中电脑。
- 不在验证付费意愿前购买高规格服务器或复杂托管组件。
- 不在 App 中预置可以被提取的 ReMind 平台 API Key。
- 不把视频等高成本任务做成无上限的免费功能。

## 8. 开发顺序

1. 冻结并验证当前 1.0.2 基线。
2. 定义本地/云端统一的服务接口和账号边界。
3. 建立 PostgreSQL 多用户数据模型、任务模型和不可篡改账本。
4. 实现 API Key 加密托管和三种 AI 模式。
5. 将微信、链接、图片、视频和 ASR 迁入异步 Worker。
6. 增加 App 登录、模式选择、余额、费用确认和任务状态界面。
7. 完成本地端到端测试后，再部署腾讯云香港环境。
