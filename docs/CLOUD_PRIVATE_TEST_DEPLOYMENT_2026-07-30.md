# ReMind 腾讯云香港隔离测试环境

> 建立日期：2026-07-30  
> 用途：阶段 7 私密测试前的第一台隔离云端环境  
> 当前状态：基础环境、私有对象存储、异地加密备份和临时 HTTPS 入口已部署并验证；尚未连接 App、真实 AI 供应商或收费入口

## 一、实际环境

- 腾讯云轻量应用服务器，中国香港一区；
- Ubuntu Server 22.04 LTS；
- 实机可用资源约为 2 核 CPU、3.6 GiB 内存、69 GiB 系统盘；
- 主机名：`remind-hk-test-01`；
- 部署版本：Git 提交 `3761c7f`；
- Docker Engine 29.6.2，Docker Compose 5.3.1。

公网 IP、SSH 私钥、数据库密码、凭据加密主密钥和未来的供应商 Key 不写入 Git 文档。

## 二、已经完成

### 主机安全

- 已安装系统更新和最新安全内核，并启用自动安全更新；
- SSH 只允许 `ubuntu` 用户使用密钥登录，已关闭密码登录、交互式密码和 root 登录；
- 已启用 Fail2ban，SSH 在 10 分钟内失败 5 次会封禁 1 小时；
- 已启用 UFW，默认拒绝入站，只预留 SSH、HTTP 和 HTTPS；
- 腾讯云公网防火墙只开放 SSH、HTTP 和 HTTPS；
- 数据库 `5432` 和内部 API `8790` 只监听 `127.0.0.1`，公网探测均为关闭。

### 云端运行时

- PostgreSQL、数据库迁移、API、Worker 和每日备份均通过 Docker Compose 运行；
- API 和 PostgreSQL 均通过健康检查；
- Worker 已安装 FFmpeg；
- 数据库已经应用 12 个迁移，共 23 张业务表；
- 用户、笔记、任务和账本数据均为 0，没有迁移现有本地数据；
- 媒体供应商模式保持 `disabled`，不会访问真实模型或产生模型费用；
- 平台 AI Key、托管价格和收费入口均未启用；
- 服务设置了 CPU、内存、进程数和容器日志上限，避免单个任务拖垮整台主机。
- API 与 Worker 已使用同地域中国香港私有 COS；凭据保存在服务器 `0600` 私密环境文件中；
- COS 最小权限仅覆盖指定桶 `users/*` 对象，真实加密写入、读取、下载校验和删除冒烟测试已通过。

### 临时 HTTPS 公网入口

- 私密测试临时域名确定为 `remind.43-129-237-189.sslip.io`，当前 A 记录解析到香港服务器；
- 已加入固定版本的 Caddy HTTPS 网关、HTTP 自动跳转、安全响应头和匿名认证接口限流；
- Caddy 只能访问 API 前端网络，不能加入 PostgreSQL 所在的后端网络；
- API、Worker、迁移和备份镜像已按提交 `0e1f84c` 重新构建并恢复健康；
- 腾讯云公网防火墙已单独放行 TCP `80` 和 `443`，没有开放 `8790` 或 `5432`；
- Caddy 已通过 Let’s Encrypt 为临时域名签发可信证书，并自动管理续期；
- 外部验证 HTTP 返回 `308` 并跳转 HTTPS，HTTPS 健康和数据库就绪接口均返回 `200`；
- HTTPS 响应已包含 HSTS、禁止嗅探、禁止嵌入、禁止索引和无来源信息等安全响应头；
- 外部探测确认 `8790` 和 `5432` 关闭，Caddy 容器也无法解析或连接 PostgreSQL；
- 匿名注册限流实测前 5 次进入业务校验，第 6 次返回 `429 rate_limited`；
- API、Worker 和 Caddy 当前日志未发现认证头、API Key 或云密钥标记。

### 本地健康巡检

- 已安装只读的 `remind-health-check.timer`，开机启用并每 5 分钟运行；
- 检查 HTTPS、5 个长期容器、磁盘、内存和最近数据库备份；
- 当前阈值为磁盘 80%、内存 90%、完整备份最长 30 小时；
- 正常和故障路径均已实机验证，首次定时巡检成功；
- 巡检只写入 systemd journal，不读取私密环境文件，不自动重启或删除数据；
- 腾讯云资源告警和费用预算仍需在控制台绑定通知对象。

### 备份验证

- 每日 PostgreSQL 备份容器已经生成首份备份；
- 备份脚本使用私有默认权限，备份目录仅管理员和备份进程可访问，新生成的备份文件已验证为 `0600`；
- 已把真实备份恢复到临时数据库，核对通过 23 张表和 12 个迁移；
- 临时恢复数据库已删除；
- 当前备份仍只在同一台服务器上，不等同于异地备份；
- 当前 PostgreSQL 备份不包含媒体对象，媒体对象仍需要单独接入 COS 和备份策略。
- PostgreSQL 备份已使用 AES-256-GCM 客户端加密后上传到新加坡独立私有 COS；
- 新加坡备份账号没有删除权限，远端当前版本保留 30 天，真实下载、解密和临时数据库恢复演练已通过；
- 备份恢复密钥同时保存在服务器私密环境文件和当前 Mac 系统钥匙串。

## 三、部署目录

- `/opt/remind/releases/<git-commit>`：不可变版本目录；
- `/opt/remind/current`：当前版本软链接；
- `/opt/remind/shared/remind.env`：仅服务器保存的私密环境变量，权限 `0600`；
- `/opt/remind/shared/backups`：数据库备份目录；
- Docker 命名卷：PostgreSQL 数据和当前临时对象数据。

发布使用 Git 提交归档，不把本机未提交文件、私钥或 `.env` 上传到服务器。

- 还没有云 KMS；
- 本地健康巡检已启用，腾讯云资源告警、费用预算和外部通知仍待配置；
- 还没有启用微信真实连接、真实媒体供应商、托管额度或充值；
- 还没有完成移动、联通、电信的 7 至 14 天网络测试。

## 六、回滚原则

- 每次发布必须保留对应 Git 提交的版本目录；
- 数据库变更前必须生成可恢复备份；
- 回滚应用版本不能自动回滚或覆盖数据库；
- 现有 `remind.db`、SecureStore、Cloudflare D1、微信配置和 Obsidian 授权不迁移、不删除；
- 发生异常时优先关闭公网入口和媒体供应商，不删除数据卷。
