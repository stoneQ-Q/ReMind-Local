# ReMind 腾讯云私密测试监控与费用保护

> 建立日期：2026-07-30  
> 适用环境：腾讯云香港私密测试服务器  
> 原则：监控只读、先通知后处理，不自动删除数据、重启数据库或启用收费功能

## 一、服务器本地巡检

服务器已安装 `remind-health-check.timer`，开机后自动启用，每 5 分钟运行一次。

巡检内容：

- PostgreSQL、API、Worker、备份和 Caddy 容器是否仍在运行；
- PostgreSQL、API 和 Caddy 的 Docker 健康状态；
- 公网 HTTPS `/ready` 是否同时返回 API 与数据库就绪；
- `/opt/remind/shared` 所在磁盘使用率是否低于 80%；
- 主机内存使用率是否低于 90%；
- 最近一份完整 PostgreSQL 备份是否在 30 小时内生成。

巡检不会读取 `.env`、API Key、数据库密码或 COS 密钥，也不会自动重启、删除或修改数据。

常用检查命令：

```bash
systemctl status remind-health-check.timer
sudo systemctl start remind-health-check.service
journalctl -u remind-health-check.service --since today
```

正常日志以 `remind_health_ok` 开头，异常日志以 `remind_health_alert` 开头，服务会以失败状态退出，方便定位具体检查项。

## 二、腾讯云资源告警

已在腾讯云可观测平台创建并绑定当前香港实例的两条策略：

- `ReMind-HK-resource-alert`：基础资源告警；
- `ReMind-HK-traffic-package-alert`：网络流量包剩余量告警。

私密测试阶段使用以下阈值：

| 指标 | 条件 | 持续时间 | 用途 |
| --- | --- | --- | --- |
| CPU 使用率 | 大于等于 85% | 连续 5 分钟 | 发现视频处理或异常任务占满 CPU |
| 内存使用率 | 大于等于 85% | 连续 5 分钟 | 在系统触发 OOM 前通知 |
| 磁盘使用率 | 大于等于 80% | 连续 5 分钟 | 给备份和临时媒体清理留出处理时间 |
| 外网出带宽使用率 | 大于等于 80% | 连续 5 分钟 | 发现异常下载或带宽瓶颈 |
| 流量包剩余量 | 小于等于 20% | 检测到一次 | 避免超出套餐流量后产生额外费用 |

通知建议：

- 通知对象选择主账号本人；
- 开启短信、邮件和站内信；
- 通知时段选择全天；
- 开启恢复通知；
- 暂不配置自动扩容、自动重启或其他自动操作。

## 三、费用预算

私密测试阶段已建立「月度费用预算」：

- 预算名称：`ReMind-private-test-monthly`；
- 周期：月度，持续生效；
- 费用范围：全部费用；
- 账单口径：费用账单；
- 费用类型：总费用；
- 每月预算：人民币 120 元；
- 实际支出达到 80% 和 100% 时通知；
- 通知对象为主账号本人，开启短信、邮件和站内信，通知时段全天。

人民币 120 元不是授权消费额度。任何新增服务器、扩容、流量包、CDN、日志服务、模型调用或按量产品，仍须在购买前单独确认。

另在费用中心启用余额预警；阈值需根据账户实际余额设置，避免为了维持测试环境而在账户中长期存放较大金额。
