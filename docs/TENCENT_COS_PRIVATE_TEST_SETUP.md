# ReMind 腾讯 COS 私密测试配置

> 建立日期：2026-07-30  
> 当前状态：代码适配器已完成，尚未创建存储桶、子账号或密钥  
> 适用阶段：腾讯云香港单人和小规模私密测试

## 一、推荐选择

创建存储桶时使用以下配置：

- 存储桶类型：通用存储桶；
- 地域：中国香港 `ap-hongkong`，与当前服务器保持同地域；
- 存储类型：标准存储，暂不选择低频、归档或智能分层；
- 多 AZ：关闭，私密测试阶段先控制成本；
- 访问权限：私有读写；
- 版本控制：关闭，避免应用删除临时文件后仍持续保留历史版本；
- 服务端加密：SSE-COS／AES-256；
- CDN、全球加速、静态网站、图片处理和日志存储：全部关闭；
- CORS：不配置，手机不会直接访问 COS；
- 防盗链：当前不依赖，所有访问都由服务端签名；
- 生命周期：增加“7 天后终止未完成分块上传”的规则，为未来的直传模式兜底。

建议桶名称填写 `remind-private-hk`。腾讯云最终会自动使用带 APPID 后缀的完整名称，例如 `remind-private-hk-1250000000`；实际完整名称必须从控制台复制，不能自行猜测。

## 二、为什么暂时不让手机直传

当前 App 已有安全的 4 MB 分片续传协议。私密测试阶段保持这个协议：

1. 手机把分片上传到 ReMind HTTPS API；
2. 服务器在私有暂存目录完成大小、SHA-256 和文件签名校验；
3. 校验通过后，服务器通过同地域内网把完整对象写入私有 COS；
4. COS 使用 SSE-COS 加密静态数据；
5. PostgreSQL 只保存用户归属、对象键、大小和 SHA-256，不保存二进制；
6. Worker 通过服务端凭据读取和删除对象。

手机不会接触长期 COS SecretKey，也不会获得公开对象地址。以后用户量和大视频上传量明显增加时，再启用短期签名直传。

## 三、当前费用预估

腾讯云当前中国香港标准存储按量价格为约 `0.136 元/GB/月`。因此只计算存储容量时：

- 10 GB：约 1.36 元/月；
- 50 GB：约 6.80 元/月；
- 100 GB：约 13.60 元/月。

同地域腾讯云服务器与 COS 之间默认使用内网，上下行流量免费，但读写请求仍计费。个人账号如果是第一次开通 COS，官方当前提供 50 GB 标准存储容量 6 个月免费额度；是否符合必须以资源包管理页面为准。

私密测试初期不购买资源包，先使用按量计费，并设置：

- 月度费用预警：5 元；
- 月度费用上限提醒：10 元；
- 每周检查一次存储容量、请求次数和异常流量；
- 不开启全球加速、CDN、数据万象或跨地域复制。

这里的估算不包含未来的异地备份费用。跨地域复制会产生额外的存储、请求和跨地域流量费用，因此要单独评估后再开启。

## 四、最小权限账号

不要把腾讯云主账号永久密钥放到服务器。应创建一个只允许编程访问的 CAM 子账号：

- 不允许控制台登录；
- 不授予财务、服务器、数据库或其他云产品权限；
- 不授予创建、删除存储桶或修改桶权限的能力；
- 仅允许操作指定桶的 `users/*` 对象；
- 创建完成后只把 SecretId 和 SecretKey 写入服务器私密环境文件；
- 密钥不得发送到聊天、写入 Git、App、截图或日志。

将下方的 `${APPID}` 与 `${BUCKET_NAME_WITH_APPID}` 替换成控制台真实值后创建自定义策略：

```json
{
  "version": "2.0",
  "statement": [
    {
      "effect": "allow",
      "action": [
        "name/cos:PutObject",
        "name/cos:GetObject",
        "name/cos:HeadObject",
        "name/cos:DeleteObject"
      ],
      "resource": [
        "qcs::cos:ap-hongkong:uid/${APPID}:${BUCKET_NAME_WITH_APPID}/users/*"
      ]
    }
  ]
}
```

服务器不需要 `ListBucket`、修改 ACL、修改 Policy、删除 Bucket、CDN 或数据万象权限。

## 五、服务器启用条件

以下条件全部满足后才能把 `REMIND_OBJECT_STORE_PROVIDER` 从 `local` 改为 `tencent_cos`：

- 存储桶确认为中国香港、私有读写；
- 完整桶名和 APPID 已核对；
- CAM 子账号最小权限策略已生效；
- SecretId 和 SecretKey 已通过不显示明文的方式写入服务器；
- 本地对象数据库仍为空，或已有明确迁移计划；
- COS 冒烟测试完成加密写入、读取、下载和删除；
- 冒烟对象已经删除；
- API、Worker 和数据库重启后均健康；
- 手机上传流程完成一次小图片和一次中断续传测试；
- 账单预警已经设置。

当前云端业务表为空，因此首次从本地对象卷切换到 COS 不需要迁移用户文件。切换后不能在已有对象的情况下随意改回 `local`，否则数据库记录与实际对象提供商会不一致。

## 六、回滚

COS 启用失败时：

1. 停止 API 和 Worker，避免继续创建新文件记录；
2. 确认数据库中没有已成功写入 COS 的业务文件；
3. 将提供商改回 `local`；
4. 重启并验证 API、Worker 和数据库；
5. 保留 COS 桶和审计记录，不立即删除，以便调查；
6. 不删除本地数据卷、PostgreSQL 卷或现有备份。
