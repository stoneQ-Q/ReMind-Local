# ReMind 本地云端环境

这个目录用于在开发机上运行与云厂商无关的云端基础设施。当前包含 PostgreSQL、第一版多用户数据模型、最小 API 和异步 Worker，不会连接或修改现有的 `remind.db`、D1 或微信配置。

## 前置条件

- Docker Desktop 或其他支持 Docker Compose 的兼容运行环境。
- Docker 引擎已经启动。

## 首次启动

1. 将 `.env.example` 复制为 `.env`。
2. 把示例密码替换为仅用于本机开发的随机长密码。
3. 在本目录执行 `docker compose up -d --build`。
4. 执行 `docker compose ps`，确认 PostgreSQL 和 API 显示为 `healthy`，Worker 显示为运行中。

`migrate` 服务会在 API 和 Worker 启动前按文件名顺序执行 `db/migrations`，并保存文件校验值。已经执行的迁移如果被修改，启动会直接失败，避免不同环境出现无法发现的 schema 差异。

## 本地端口

- PostgreSQL：`127.0.0.1:5432`
- 云端 API：`127.0.0.1:8790`
- API 进程健康检查：`GET /health`
- API 与数据库联合就绪检查：`GET /ready`

这些端口只绑定本机，不会直接暴露给同一局域网中的其他设备。未来 App 联调时通过单独的开发入口提供访问。

## Worker 骨架

当前 Worker 只执行注册过的任务类型，包括零费用的 `system.noop`、按连接调度的 `wechat.poll` 和按笔记调度的 `link.parse`。通用执行器提供：

- 多个 Worker 使用数据库行锁和唯一租约，不会同时领取同一任务；
- 每个用户先选出一个候选任务，再按“最久未获得执行机会的用户”调度，避免单个用户占满队列；
- 每次执行都有独立历史记录和递增尝试次数；
- 失败按指数退避重试，达到上限后才进入最终失败；
- 每个任务有超时上限，即使处理器没有响应取消信号，执行器也会停止等待；
- 排队中和运行中的任务都可以请求取消；
- Worker 崩溃后，过期租约会被回收并重试，旧 Worker 的完成结果因租约不匹配而失效；
- 原始 `input_json` 在重试、超时、取消和崩溃恢复过程中保持不变；
- 有费用预占的任务最终失败或取消时会自动释放预占。
- AI 任务只有两种情况可以被领取：用户已明确授权的零费用 BYOK 任务，或已经完成费用预占的托管任务；
- 托管任务处理器必须返回实际成本，结果、实际扣费、预占差额释放和执行历史在同一个数据库事务中完成；
- 实际成本缺失、超过预占或结果无法安全保存时，任务会失败且不会产生实际扣费。

API 提供 `GET /api/v1/jobs/:jobId` 查询当前用户自己的任务状态，以及 `POST /api/v1/jobs/:jobId/cancel` 请求取消。媒体工作流目前只提供可信内部方法，尚未开放给 App。

## 微信云端轮询

云端 Worker 已具备按用户隔离的微信 iLink 轮询能力：

- 每个用户最多有一个有效连接，调度任务只保存连接 ID 和连接代次，不含令牌、微信用户 ID 或其他凭据；
- 微信凭据使用与用户 API Key 相同的 AES-256-GCM 加密边界，并额外绑定用户 ID 和连接 ID；
- 出站地址仅允许 HTTPS 的 `weixin.qq.com` 官方域名及其子域，避免凭据被发送到任意地址；
- 只接收绑定微信用户发来的文字、语音转写和文件名，按外部消息 ID 去重后写入该用户自己的笔记；
- 轮询失败不会推进游标，交给通用任务执行器退避重试；重新绑定会增加连接代次，使旧任务失效；
- 确认回复使用稳定的客户端 ID，降低 Worker 异常退出后重复回复的概率。

目前尚未开放微信凭据提交或扫码绑定 API。开发主库也没有自动读取、复制或迁移 `~/.remind-weixin/config.json`；现有 Mac 本地网关继续独立运行，作为自助部署版和云端改造期间的回退。联调使用独立临时数据库、假凭据和模拟微信协议，不会连接真实微信服务。

## 网页与小红书解析

带有公开 HTTP/HTTPS 链接的云端笔记会由 `link.parse` Worker 异步处理：

- 任务输入只保存笔记 ID 和处理代次，原始网址仍只保存在该用户自己的笔记中；
- 每次请求和每次重定向都会重新校验地址，禁止账号密码 URL、非常规端口、本机地址、私有/保留 IP、局域网域名和云元数据地址；
- DNS 解析后的全部地址必须是公网地址，请求会固定到已经校验的地址，降低 DNS 重绑定风险；
- 最多允许 4 次重定向、单次请求 15 秒、任务总计 45 秒、压缩前后页面均不超过 2 MB，正文最多保存 24,000 字；
- 普通网页保存标题、说明、站点和正文；小红书图文最多保存 12 个经过域名校验的 HTTPS 图片地址；
- 小红书视频目前只保存“视频”类型和可用时长，不把页面中的临时视频下载地址写入笔记、任务输入或任务结果。

当前测试使用模拟网页响应，不访问真实网站。小红书页面遇到登录、安全验证或页面结构变化时会保留原始笔记并将处理标记为失败；视频下载和转写属于后续媒体 Worker，不在本步骤中执行。

## 对象存储与临时文件

媒体二进制不会写入 PostgreSQL。当前开发环境使用本地文件系统适配器和独立的 `remind-object-data` Docker 卷，数据库只保存用户归属、对象键、类型、大小、SHA-256、用途和生命周期状态：

- 对象键由服务端生成，固定为 `users/<user_id>/<purpose>/<随机文件ID>.<扩展名>`，不使用用户文件名作为路径；
- 每个数据库约束和读取方法都会再次校验 `user_id`，跨用户文件 ID 无法读取；
- 当前允许常见 JPEG、PNG、WebP、MP3、M4A、WAV、WebM、Ogg、MP4 和 MOV；图片上限 20 MB、音频 100 MB、视频 1 GB；
- 写入使用私有目录、`0600` 文件权限和原子落盘；读取时核对数据库大小与 SHA-256；
- 临时文件有效期限制为 5 分钟至 7 天，默认 24 小时；源文件和结果文件不会因临时文件规则被误删；
- Worker 每轮最多领取一个到期文件，使用短租约和删除尝试历史；进程崩溃、对象已不存在和临时删除失败均可安全重试；
- 超过 10 分钟仍未完成入库的 `pending` 半成品会被回收，删除失败期间文件保持不可读取。

对象存储方法目前只供可信内部代码和测试使用，尚未开放上传 API，也没有生成公开或长期签名地址。接口已预留 `local`、`tencent_cos` 和 `aliyun_oss` 三种供应商标识，但本地阶段只实现 `local`；部署腾讯云时替换适配器，不改变任务和数据库契约。

PostgreSQL 备份只包含对象元数据，不包含 `remind-object-data` 中的二进制文件。私密测试部署必须使用 COS 的版本控制/生命周期和独立备份策略；不要把本地对象卷当作生产备份。

## 媒体处理工作流

云端 Worker 已建立图片、音频和视频的持久化处理边界：

- 图片使用 `ai.image` 单步分析；
- 音频使用 `ai.transcription` 转写，失败由通用执行器重试；
- 视频拆分为临时音轨准备、语音转写和文字总结三个独立步骤；
- 任务输入只保存媒体请求 ID、处理代次和阶段，不复制源文件 ID、对象键或二进制内容；
- 每一步完成后由调度器校验结果并推进下一步，Worker 崩溃不会跳过中间状态；
- 视频临时音轨完成转写后立即到期，由对象清理 Worker 删除；源文件不会被临时清理；
- 整个请求支持取消、跨用户隔离和幂等创建。

当前只有确定性的模拟供应商，专门用于无费用的故障测试。它默认关闭，只有显式设置 `REMIND_MEDIA_PROVIDER=mock` 才会注册媒体处理器；未知配置会使 Worker 拒绝启动。正式供应商适配器和 App 创建入口尚未接入，因此不会把模拟结果误当作真实分析返回给用户。

## 匿名账号

当前云端 API 提供：

- `POST /api/v1/auth/register`：创建匿名账号、首台设备、30 天会话和恢复码；
- `POST /api/v1/auth/recover`：使用恢复码为原账号增加一台设备；
- `POST /api/v1/auth/refresh`：使用长期设备密钥换发新的 30 天会话；
- `GET /api/v1/users/me`：验证会话并读取当前账号；
- `GET /api/v1/devices`：只读取当前账号自己的设备。

恢复码、设备密钥和会话令牌只在创建时返回原始值。数据库分别保存 SHA-256 哈希，不保存可还原的原始值。恢复码支持忽略大小写、空格和连字符，但必须妥善保管；服务端无法替用户找回原始恢复码。

App 在会话剩余 7 天或更少时使用设备密钥自动续期。续期成功后，原会话令牌立即失效，新的会话继续有效 30 天。正常使用不会要求用户定期输入恢复码；只有设备密钥丢失、设备被撤销或更换手机时才需要恢复码。

## AI 模式与用户 API Key

每个账号默认使用 `disabled`，可以切换为：

- `disabled`：关闭 AI，不读取任何模型凭据；
- `bring_your_own_key`：使用用户自己配置的 DeepSeek 或智谱 Key；
- `managed`：使用 ReMind 托管额度；预付费安全层已完成，真实模型供应商调用尚未接入。

云端 API 提供：

- `GET /api/v1/ai/settings`：读取模式和已配置供应商；
- `PUT /api/v1/ai/settings`：切换 AI 模式；
- `PUT /api/v1/ai/credentials/:provider`：新增或替换用户 Key；
- `DELETE /api/v1/ai/credentials/:provider`：物理删除用户 Key。

API 永远不返回完整 Key，只返回供应商、末四位和更新时间。Key 使用 AES-256-GCM 加密，每次加密使用独立随机 nonce，并将用户 ID、供应商和密钥版本绑定为附加认证数据；密文被复制给另一用户或供应商后无法解密。

本地开发使用 `.env` 中的 32 字节主密钥。轮换时：

1. 将旧版本与旧密钥加入 `REMIND_CREDENTIAL_KEY_RING_JSON`；
2. 把新的版本和密钥设置为当前活动密钥；
3. 执行 `docker compose run --rm api node dist/rotate-credentials.js`；
4. 验证所有凭据都已更新后，再从 key ring 中移除旧密钥。

正式收费前必须把本地主密钥适配器替换为云 KMS，不能把生产主密钥长期保存在普通环境变量中。

## 备份

`backup` 服务启动后会立即生成一份 PostgreSQL 自定义格式备份，之后默认每 24 小时备份一次，并保留最近 7 天。备份文件位于本机 `cloud/backups`，已排除在 Git 之外。

执行 `./scripts/verify-backup-restore.sh` 可以：

1. 生成一份手动备份；
2. 创建临时数据库；
3. 完整恢复；
4. 对比表数量和迁移数量；
5. 自动删除临时数据库。

备份文件包含用户私有数据和凭据密文，不能上传到公开仓库。部署到云端后，备份还必须进行独立加密并复制到异地存储。

## 预付费账本与成本保护

金额统一使用人民币微元整数保存：`1 元 = 1,000,000 micros`，不使用浮点数。托管任务按以下顺序处理：

1. 在发起第三方调用前预估并预占费用；
2. 任务成功后按实际费用扣除，多余预占立即释放；
3. 任务失败或取消时释放全部预占；
4. 每一步写入不可修改、不可删除的账本记录，并保存操作后的余额快照；
5. 幂等键保证网络重试和并发重试不会重复扣款。

本地开发默认硬上限为：单任务 5 元、单用户每日 10 元/月度 100 元、全平台每日 100 元/月度 1000 元。这些只是保守的开发值，私密测试前必须依据模型报价和实测成本重新核定。

客户端目前只能调用 `GET /api/v1/billing/account` 和 `GET /api/v1/billing/ledger` 查询自己的余额与明细。系统没有开放充值 API；内部入账方法只能在可信支付回调或审计过的管理工具中调用。

执行 `npm run smoke:billing` 会创建一个独立临时数据库，验证账本不可篡改、预占/结算/释放、并发幂等、余额不足、各级预算上限和负余额保护，随后自动删除该临时数据库，不向开发主库写入测试账目。

### 高费用确认

高于或等于本地默认阈值 1 元的任务必须经过服务端报价和用户二次确认：

- 费用只能由服务端定价器写入，客户端没有“自行填写预计费用”的接口；
- 报价默认 15 分钟过期，过期后必须重新报价；
- 未确认的高费用任务无法预占余额，也不会进入 Worker；
- `GET /api/v1/jobs/:jobId/quote` 只读取当前用户自己的报价；
- `POST /api/v1/jobs/:jobId/confirm` 明确确认报价并执行幂等预占。

当前只有内部报价创建方法，尚未开放真实任务创建接口。阶段 5 接入具体模型和媒体任务时，由各任务的服务端定价器调用它。

### 第三方异常熔断

DeepSeek、智谱等供应商的调用结果必须通过统一健康记录方法上报。本地默认在 5 分钟内连续失败 3 次后：

1. 自动把供应商标记为暂停；
2. 写入一条不可丢失的内部严重告警；
3. 阻止新的报价和新的费用预占；
4. 保持暂停状态，成功探测不会自行恢复，必须由内部运维方法人工恢复。

阶段 5 的真实 Worker 在每次调用前还必须再次检查暂停状态，并在成功或失败后更新健康记录。阶段 7 部署腾讯云时，再将内部告警表接入短信、邮件或云监控通知。

## 停止与清理

- 停止但保留数据：`docker compose stop`
- 再次启动：`docker compose start`

不要执行 `docker compose down -v`，它会删除本地 PostgreSQL 数据卷和对象存储卷。需要重建测试数据库时，也必须先确认其中没有需要保留的数据。

## 当前数据边界

- 云端所有私有实体都包含 `user_id`。
- 设备密钥和会话令牌只保存哈希。
- 微信凭据和用户 API Key 只保存密文；异步任务输入不保存完整凭据。
- 文件只保存对象存储引用，不把二进制内容塞入数据库。
- 账本只允许追加，数据库触发器拒绝修改和删除历史记录。
- 任务使用每用户幂等键，避免重试造成重复执行或重复扣费。
